112 ways to draw a tool page

Every one of these is a 1200 × 630 open-graph card, rendered live at full size and scaled down — so what you see is exactly what a timeline sees. Families 01–20 draw one tool, the YouTube Thumbnail Downloader, twenty ways in five colourways each. Family 21 is the house style: the centred browser frame on the site's own dark ground, shown once for each of the twelve platforms registered in config/site.ts, each with a real tool and a sticker in that network's own primary colour.

SIZE

1200 × 630, nothing else

Facebook, LinkedIn, Slack and X all crop to 1.91:1. Anything else gets cropped by someone. Keep 60px of margin clear on every edge — X trims the sides, Slack trims the top.

TYPE

One idea, ≥ 56px

A card is read at 360px wide in a feed. That 70px headline becomes 21px. Two short lines beat one long one; never more than nine words.

TRUST

Brand mark + domain

The domain in the card is what people remember when they don't click. Same mark position on every card so the set reads as one publisher across a hundred shares.

HOOK

Say the free part

"Free · no sign-up" in a chip lifts click-through on utility pages more than any illustration. It answers the only objection a searcher has.

ALT

Text lives outside the pixels

Google reads og:image:alt and the surrounding markup, not the image. Describe the tool there; treat the card as pure click-bait for humans.

SCALE

One template, every tool

These are drawn in HTML — the same layout Satori renders in opengraph-image.tsx. Name, tagline, platform and accent come from the tool record.

How to ship it. Add apps/web/src/app/(site)/tools/[slug]/opengraph-image.tsx next to the page, export size = { width: 1200, height: 630 }, fetch the tool by slug and draw the family you picked. Satori supports flexbox, absolute positioning and linear-gradients — every card here stays inside that subset except the blur in Glass (bake it as a gradient instead) and CSS grid (use flex wrap).

export const size = { width: 1200, height: 630 };
export const contentType = "image/png";

export default async function Image({ params }: { params: { slug: string } }) {
  const tool = await getTool(params.slug);          // name, tagline, platform, tier
  return new ImageResponse(<ToolCard tool={tool} />, size);   // one family, 60+ cards
}

Then point the metadata at it — openGraph.images and twitter.card = "summary_large_image" — and always send og:image:alt with the tool's real description. Re-scrape once with the Facebook Sharing Debugger and X's Card Validator; both cache a bad first fetch for days.
