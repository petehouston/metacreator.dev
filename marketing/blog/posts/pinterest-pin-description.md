A Pinterest Pin description can run to 800 characters and **does not appear in the home
or search feed** — Pinterest uses it to work out what the Pin is about
([Pinterest specs](https://help.pinterest.com/en/business/article/pinterest-product-specs)).
That single fact should change how you write it: it is relevance copy, not a caption.

## What a Pin description is for

| Field | Audience |
| --- | --- |
| Title | People, in feeds — roughly the first 40 characters |
| Description | Pinterest, for matching; people, on the closeup |
| Board name | Both |
| Destination page | Both |

So the description is where the query and its natural variants belong, written as
sentences rather than as a keyword list — the same rule that governs any search-facing
text, because a machine reading prose gets more signal from it than from a comma-separated
pile.

## A structure that works

1. **One sentence saying exactly what the Pin is**, containing the main query.
2. **One or two sentences of useful detail** — what the reader gets, what is included,
   what makes it different — carrying natural variants of the query.
3. **One sentence on what to do next**, if there is a genuine next step.

Three or four sentences. The 800-character ceiling is a ceiling, not a target, and a
description padded to fill it reads as machine-written to the only machine that matters.

## What to leave out

- **Hashtag walls.** Pinterest is a keyword search engine. A row of tags carries less
  information than a sentence.
- **Emoji as words.** They add no matchable text.
- **Repetition of the exact phrase.** Once in the title and once or twice naturally in
  the description is the whole of it.
- **Anything the image already says.** The description should add, not caption.

## The title does the human half

Up to 100 characters, with roughly the first 40 shown in feeds. That is the text
competing for a glance in a column of tall tiles, so it needs the query and the benefit,
front-loaded.

## Boards are part of the description

A Pin saved to a subject-specific board inherits that context. "Small kitchen storage"
tells Pinterest something; "Things I like" tells it nothing, and it dilutes every Pin on
it.

:::faq
Q: Do Pinterest Pin descriptions show in the feed?
A: No. They appear on the Pin closeup and are used by Pinterest for relevance matching -
which is why they should be written as prose containing your keywords.
Q: How long should a Pin description be?
A: Three or four sentences. The limit is 800 characters, but padding to fill it adds
nothing.
Q: Should I use hashtags in a Pin description?
A: No. Write sentences. Pinterest matches queries against text rather than tags.
Q: Does the Pin title matter more than the description?
A: They do different jobs. The title earns the click in feeds; the description helps
Pinterest decide which searches to show the Pin in.
:::
